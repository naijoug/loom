Loom — 界面切换逻辑 · Navigation flow
一个 Task 同时只有一个状态；状态决定打开哪个详情视图。Task Board 是路由中枢，面包屑 mini-stepper 在同一任务的阶段间切换。
① 向前推进 · 每屏的主操作
▶
New task → 打开 Plan 聊天室
▶
Plan 里 Create tasks from plan → 生成任务 → Task Board
▶
Board 上 ▶ Run 某 Todo → 状态 Todo→In Progress → 打开 Agent session
▶
session 里 Mark ready for testing → 状态→Testing → 多终端测试
▶
Testing 全部通过 → 状态→Done → 总结；严重失败 → Blocked（回 Board）
▶
Done 的 Start follow-up → 新开一个 Plan 聊天室
② 随处跳转 · 侧栏 & 面包屑
1
左侧项目列表：点任务→按其状态打开对应详情；点项目名→该项目 Board。（随机访问）
2
面包屑 mini-stepper（Plan ✓ · Implement ● · Test ○ · Done ○）：反映该任务状态，可回看同一任务的早前阶段。
3
Board = 状态编辑器：在看板上改任务状态，即决定它打开哪个详情视图（“根据完成状态修改状态”）。
↻ Testing 内部还有 fix → restart → re-test 的 debug 循环，不切换主界面。
③ 三种 session 都属于「一个任务」
●
Plan = 讨论 session（多 Agent 聊天）→ 产出任务
●
In Progress = 执行 session（agent loop：think→read/edit/run→diff）
●
Testing = 调试 session（前后端终端 + Debug agent 循环）
