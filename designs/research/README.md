## 整体结构

```text
┌──────┬──────────────────────┬──────────────────────────────────────────────┐
│ rail │ Research 历史    [+] │ 标题                    [停止|重试] 📁 📜 🗑 │
│ 52px │ ● 问题标题      loom │ Agent · 模型 · 项目 / 未选项目                  │
│      │ ● 问题标题   未选项目 │──────────────────────────────────────────────│
│ 💬   │                      │ 问题 1  问题文本                               │
│ 🎓   │                      │   [警告] 报告 Markdown（结论/证据/引用/待确认）  │
│ 🔭   │                      │ 问题 2  问题文本  [延续 Agent 会话]             │──┐
│      │                      │   报告 …                                      │源│
│ ⚙    │                      │ ┌──────────────────────────────── 追问 ┐     │码│
│      │                      │ └──────────────────────────────────────┘     │栏│
└──────┴──────────────────────┴──────────────────────────────────────────────┴──┘
```

- 第二栏沿用 `styles/workspace.css` 的列表侧栏（与 Learn 相同的 `.chat-*` 骨架）；状态圆点：运行中 `--chat-accent`、完成 `--chat-ok`、失败 / 停止 / 中断 `--chat-danger`。右侧小字为项目名或"未选项目"。
- 主区域为一串问答：问题行（序号、问题、上下文标签、非完成状态标签），其下依次是运行中提示、错误摘要（原始 stderr 收在"详情"中）、警告框、引用失效提示、报告。
- 上下文标签只在追问上出现："延续 Agent 会话"（原生续接）或"已回放此前问答"（回放历史）。
- 追问框固定在问答末尾；运行中禁用。Enter 发送，Shift+Enter 换行，输入法组合中不发送。
- 共享 `SourceViewer` 在右侧打开（仅有项目时显示"浏览源码"按钮）；`loom-src:` 链接打开并高亮引用行，失效引用带删除线标记。

## 新建表单

问题（多行，必填，≤8000 字）→ Agent（共享 `AgentPicker`，向下展开；模型输入仅在诊断报告 `modelSelection` 时显示）→ 项目（"不选项目"或已在 Loom 打开的项目）+ 回答语言 → 说明文字 → "开始研究"。只读说明写在副标题里。

## 操作

| 状态 | 主按钮 | 其它 |
|---|---|---|
| 运行中 | 停止 | 日志；删除禁用；追问禁用 |
| 最后一问失败 / 已停止 / 已中断 | 重试（重跑最后一问） | 日志、删除、追问 |
| 完成 | — | 日志、删除、追问 |

删除使用横幅二次确认。日志面板按 stdout / stderr / prompt 分页，显示最后一问的作业。
