## 关键决定

| 区域 | 规格 |
|---|---|
| 左栏 | 272px；顶部学习切换器（仓库名 + owner · commit，下拉切换），右侧 `+` 新建；下方页面目录，标题最多两行；底部状态图例 |
| 页面状态图标 | 已读 = 绿色勾圈；可阅读 = 蓝色实心点圈；生成中 = 旋转弧；未生成 = 虚线圈且标题变灰 |
| 头部 | 标题 + 元信息；进度胶囊（环形进度 + “5/13 页”，有警告时带橙点）点开弹层显示下载 / 清单（含排除说明）/ 架构 / 页面阶段；“生成剩余”为次级按钮；GitHub、日志、删除收进 `⋯` 菜单，删除标红并需二次确认 |
| 概览页 | “按学习顺序的下一篇未读页” + 继续阅读主按钮 + 已读/已生成进度条；L1–L3 三张分组卡片（窄窗口单列）；术语表一行 |
| 架构图 | HTML 模块框（全名换行）+ SVG 叠加边；层名在行上方；默认不画边；悬停/聚焦模块时：自身描边加粗，依赖为蓝色实线，被依赖为橙色虚线，其余淡化到 35%；同层边从行下方绕行；点击打开模块页 |
| 未生成页 | 虚线卡片说明 + “生成此页”主按钮 + “生成剩余”次按钮 + 运行说明；下方列出依赖 / 被依赖模块芯片 |
| 翻页 | 每页底部按学习顺序（概览 → 架构 → L1 → L2 → L3 → 术语表）显示上一页 / 下一页 |
| 窄窗口 ≤760px | 左栏变为抽屉，由头部目录按钮打开，带遮罩；头部操作换到第二行 |

## 已确认的决定

1. 去掉独立学习列表栏，改为左栏顶部切换器。
2. 架构图默认不画任何依赖边，只在悬停/聚焦时显示。
3. 已读状态只按设备保存（localStorage）。
