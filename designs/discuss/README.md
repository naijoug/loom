# Discuss MVP 布局（P7）

沿用 P5 功能栏、共享 AgentPicker / Markdown / SourceViewer；第 4 项为 MessagesSquare（⌘/Ctrl+4），默认仍进入 Chat。Learn、Research 和 Discuss 不互相导入。

- 左栏：讨论记录、运行状态、新建入口；主区：议题/参与者/项目、停止与删除。
- 新建：议题 → 2–4 位参与者（每位 Agent + 可选模型；首位主持）→ 可选已登记项目 → 报告语言。显示 2N+1 次预计调用；第二步确认后才开始，确认时锁定输入。
- 结果：独立回答 / 互评修订 / 汇总三个轮次页签，各带完成计数。桌面宽屏两列并排，不足 1050px 单列，汇总总是单列。失败错误就地展示，保留成功报告。汇总旁明确列出未纳入的第二轮参与者。
- 单项重试：确认 1 次调用，前序变化时显示后续结果“需要更新”；不自动追加调用。可以逐项更新后续回答与汇总。
- 日志：按尝试选择 stdout/stderr/prompt/执行记录；有界加载，缺失显示错误；源码引用点击在共享查看器显示范围。
- 700px：功能栏保留，记录栏堆叠到顶部，页签可换行，卡片单列。中英文、深浅色使用现有变量。

合成矩阵：`scripts/discuss-smoke.mjs`；截图在 `designs/exports/discuss/`，仅作 synthetic-web-only 证据，不替代桌面验收。
