- 范围：计划第 23 节，接入生产策略/运行桥、持久化审计及原生交互。完整 M2 和 M0–M8 仍实施中。

## 已实现

- 按固定上游区分命令前缀、单用途命令名、精确 argv、写目录、静态网络目标域名、MCP 工具和 API 方法/路径。Shell 链/管道/重定向/赋值/展开、危险操作及包装器不提供普通命令记住键；管理员请求和启用 Guarded 后的风险审批不提供记住选项。
- Rust 生成 `RememberOffer`。前端只能按当前 approval 的 binding digest 选择允许一次、此会话记住或拒绝，不能传入选择器扩展范围。审批绑定同时覆盖记住选择器，重复请求不能更改已决定的选择。
- 原始精确 argv/路径选择器作为摘要输入，不以原始精确命令作为明文授权键存盘；标签与参数沿用脱敏处理。目录显示允许范围，后续匹配还校验 realpath，符号链接改向不复用旧授权。
- 记住决定与 grant 在一个事件里提交，工具准入在同一个锁内匹配全部键并写入审计。自动准入事件带具体 `authorizationIds`，清除不能插入检查与准入之间。不同域名可由多个有效 grant 覆盖，但每个目标都必须匹配。
- 授权绑定会话、cwd、adapter/连接身份、权限模式及策略快照；不同策略或会话不会误用。用户可清除所有已记住授权，已准入调用仍依照其原决定完成，后续调用重新询问。
- 授权历史持久化，活动授权属于当前 Core 运行实例；重启加载时追加撤销记录，不自动恢复权限。前端历史显示“会话授权有效/已撤销”。普通 worker 每回合退出不视为逻辑会话结束。

## 原生验收

使用独立 `.tmp/remember-native-data`，通过 `scripts/debug.sh` 启动 `LOOM_WORKBENCH_FIXTURE=1`、`LOOM_WORKBENCH_APPROVAL_FIXTURE=1`；测试工具不写文件、不执行命令、不调用模型。

1. 首轮显示范围、生命周期与“拒绝/允许一次/此会话中记住”；选择记住后授权生效。
2. 第二轮同类请求自动完成，审批记录数量保持 1。
3. 展开已记住授权并清除，第三轮再次显示审批；再次记住以准备重启检查。
4. 正常停止、同目录重启并加载会话，历史显示两项会话授权均已撤销，不再显示有效授权列表。
5. 重启后的新请求再次弹审批，选择拒绝；最终停止预览，进程句柄 exit 0。

[原生事件与观察](m2-remember-native-results.json)确认两次记住决定、一次自动复用、用户清除与运行实例结束撤销；journal 不含 fixture 原始凭据。截图当场检查，布局记录见 [原生 UI 观察](../../../designs/workbench-m2/remember-ui-2026-10-09.md)，未另存像素文件。

## 差异和边界

- 不沿用上游 whitelist 对整个 key 转小写的做法，避免大小写敏感参数/路径共享授权；API key 增加 Source 身份；目录 key 增加实际目标；附着的 `curl -Kfile` / `wget -ifile` / `wget -e...` 不可隐藏额外目标。这些修正保留在差分与专项测试中。
- 域名选择器来自静态命令参数，不是网络 sandbox；重定向、代理、DNS 或程序内部行为不能由字符串选择器证明。未声称对任意外联提供强隔离。
- 当前每个请求最多 32 个选择器，每会话最多 1024 项活动记住记录；超范围不会自动放行。目录授权覆盖同一直接父目录，不隐式扩展到子目录。
- MCP/API 选择器已有实现和隔离测试，真实 Source 传输/认证/动态身份仍待 M4 接入；不得把选择器通过算作 Source 功能完成。
- 管理员审批与特权 broker、完整 Guarded provider、实时策略变更/待批准授权重评、Shell 会话目录例外、其他账户/SDK 功能与发行资源继续。
- 新 HTTP/Claude 验收仍待先前明确许可。当前 checkpoint 不能作为完整复刻或最终交付验收。
