# M1 实际导入与独立历史副本

日期：2026-09-30。基线：`959114c` 加本轮修改。最终源码、app SHA-256、源文件清单、离线回读和持久化报告见 [机器证据](m1-legacy-import-evidence.json)。本切片完成 macOS 旧项目格式的实际导入，不表示完整重建或全部迁移平台已完成。

## 行为与产物

- 预检指纹绑定持久化计划；准备/执行/发布前分别核对来源。旧目录只读，Chat v2 残尾保持原样。
- 引用资源与完整历史记录先写 staging，同步后按 Session 原子发布。固定来源 ID 去重；新内容与已导入记录冲突时保留已有会话，不覆盖新笔记或消息。
- 报告逐项持久化并校验。源损坏记录跳过且可诊断；资源缺失保留警告。中断重试依据已发布目录确认结果，不重复创建 Session。
- Chat 历史转录/工具摘要可阅读；未结束消息标为 interrupted。旧 Task 进入归档，完整需求、日志/计划/Review 引用和原始 JSON 作为历史保留，不转换成运行中的 DAG。
- 新权限为 Explore、连接为空，无 live Turn、PID、native resume 或旧审批继承。原始文件可含历史 invocation，但只是资源数据，不进入新执行配置。
- 文本资源经校验后预览，二进制附件逐字节复制。资源 ID 绑定 Session，不能提交文件路径绕过仓库读取。

## 验证结果

| 验证 | 证据范围 |
| --- | --- |
| `pnpm check:core` | 48 个测试入口通过：27 原内核 + 19 旧数据/导入 + 2 进程中断测试入口（含子进程 helper）；fmt、严格 Clippy、生成类型漂移和协议 TS 编译通过。 |
| 真实进程中断 | 子进程完成两项 staging，仅发布第一项后 `exit(23)`，不返回导入结果、不执行析构；重启重试得到 1 已有 + 1 新增，第二次重试两项均已有。不是断电测试。 |
| 源变更/数据完整性 | 预检过期、计划被篡改、资源变化均拒绝；源文件字节不变；二进制分块回读一致，篡改/符号链接资源被拒绝；重复导入保留新消息/笔记。最终增加了真正重启后读取篡改资源的步骤，该单项补验通过。 |
| 前端相关回归 | 13 项通过：历史分页与跨会话迟到响应、纯文本资源不执行 script、导入连点只执行一次、重试复用计划，以及原 Workbench 协议、补流、草稿和 IME。 |
| Tauri Workbench | 5 项通过；真实宿主 fixture/权限入口/退出/订阅行为保持可用。 |
| 构建 | `pnpm build` 及 `VITE_LOOM_WORKBENCH=1 CARGO_NET_OFFLINE=true pnpm tauri build --debug --bundles app` 通过。 |
| 原生端到端 | 合成项目预检 2 可读 + 1 损坏；首次导入 2 新增 + 1 跳过，重复执行 0 新增 + 2 已有 + 1 跳过；打开历史对话、展开 Read 输入输出、打开归档 Task 和计划文本；Explore 与无运行状态均可见。 |
