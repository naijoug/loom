					62 text mini-swe-agent is a Python software engineering agent that uses language models and shell commands to solve programming tasks. Its architecture separates agent control flow, model communication, and command execution through small protocols. It provides an interactive CLI, benchmark runners, configurable prompts, and a terminal viewer for saved trajectories.
					63 text A run script combines configuration with command-line options and constructs a model, an execution environment, and an agent. The agent renders initial prompts, queries the model, executes the returned actions, and adds formatted observations to the conversation. This loop continues until submission, a configured limit, or an error ends execution.
