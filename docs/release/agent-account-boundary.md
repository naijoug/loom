# Loom Beta Agent / CLI 账号边界

- **状态**: draft
- **适用阶段**: M3 隐私、安全与诊断包披露
- **关联文档**: `docs/release/privacy-note.md`、`docs/release/beta-safety-notes.md`

## 一句话边界

Loom 负责编排你本机配置的 Agent / CLI，并记录本地调用证据；真实账号的登录状态、额度、费用、服务端日志、数据保留和服务条款由对应工具与服务商决定。首轮 Beta 不提供统一托管账号，也不替第三方 Agent 承担隐私或计费责任。

## 支持的 Agent 类型

| 类型 | Beta 使用建议 | 账号责任 |
|---|---|---|
| Dummy / fixture / echo 命令 | 首次 smoke 默认选择 | 不需要真实账号，适合验证 Loom UI、流程和日志记录 |
| Codex CLI | 只在低风险项目中手工启用 | 登录、模型额度、费用、上下文发送策略由用户自己的 Codex 配置决定 |
| Claude Code | 只在理解服务商策略后启用 | 登录、订阅/额度、数据保留和服务端日志由用户自己的 Claude 配置决定 |
| OpenClaw / Hermes | 作为本地 Agent 工具按需接入 | 工具自身 profile、插件、cron、记忆和外部服务由用户配置负责 |
| 自定义 CLI | 仅配置可信可执行文件 | 命令行为、网络访问、文件访问和费用完全取决于该 CLI |

## Loom 负责什么

Loom 在本地负责：

- 保存 Agent 配置、启用状态和阶段能力边界。
- 在项目 cwd 内发起命令或 Agent invocation，并记录命令、cwd、时间、状态、退出码和阻塞原因。
- 对本地记录做统一脱敏，常见 secret 字段会替换为 `[REDACTED]`。
- 对破坏性文件操作、破坏性 Git、生产外部目标和路径逃逸执行安全策略检查。
- 在 UI 中呈现 Agent 输出、Review 结果和验证证据，帮助用户做人工确认。

Loom 不负责：

- 替用户创建、保管或续费第三方 Agent 账号。
- 保证第三方服务不会记录、保留或训练用户发送的上下文。
- 保证真实 Agent 输出正确、安全、无幻觉或适合生产执行。
- 为自定义 CLI 的脚本内容、网络请求、文件访问或供应链风险背书。
- 统一管理团队级权限、审计、预算和合规策略。

## 启用真实 Agent 前的检查

在把 Loom 从 dummy smoke 切到真实 Agent 前，请逐项确认：

1. 当前项目是临时仓库、示例仓库或低风险个人仓库。
2. Git 工作区已提交、备份或确认可回滚。
3. 任务描述不包含 token、password、API key、cookie、私钥或客户资料。
4. 你知道该 Agent 是否会把文件内容、命令输出或聊天上下文发送给外部服务。
5. 你接受该 Agent 的额度、费用、速率限制和服务条款。
6. Agent 可执行文件来自可信来源，不是未知 shell wrapper。
7. 如果命令可能写文件、安装依赖或访问网络，你已理解 Loom 的确认提示和退出方式。

未满足任一项时，继续使用 dummy / fixture / echo 命令。

## 费用与额度边界

真实 Agent 可能消耗：

- 模型 API token、订阅额度或付费 credits。
- 第三方 CLI 的 rate limit。
- 网络带宽和远程构建 / 部署资源。
- 本机 CPU、内存、磁盘和子进程资源。

首轮 Beta 的默认 smoke 不应依赖付费 Agent canary。需要测试真实账号时，应显式标记为手工场景，并在反馈中说明 Agent 类型、是否付费、是否触发额度或费用异常。

## 数据发送边界

Loom 无法替第三方 Agent 精确保证“发送了哪些 token”。实际发送内容可能来自：

- 用户在任务描述和反馈中输入的文本。
- Agent CLI 自己读取的文件上下文。
- 命令 stdout/stderr、错误堆栈、测试输出和日志。
- 自定义 CLI 的配置文件、环境变量或网络请求。

因此，真实 Agent 首轮试用应遵循最小上下文原则：用临时项目、最小复现、短日志和无机密 fixture 先跑通闭环，再逐步扩大范围。

## 自定义 CLI 红旗

不要在 Beta 中配置这些命令作为 Agent：

- 需要 `sudo`、系统权限修改或关闭安全软件的命令。
- 未知来源的一行安装脚本或远程 shell wrapper。
- 默认读取 home 目录、钥匙串、浏览器 cookie、SSH key 或云凭据的命令。
- 默认部署、清库、迁移生产数据或修改线上权限的命令。
- 会把完整仓库压缩并上传到未知服务的命令。

如果必须测试高风险能力，先在完全隔离的临时账号、临时仓库和无真实凭据环境中做手工验证；不要作为邀请制 Beta 的常规任务。

## 反馈时需要说明的账号信息

发送反馈时不要提供 token 或账号截图。可提供这些非敏感字段：

- Agent 类型：dummy / Codex / Claude Code / OpenClaw / Hermes / custom CLI。
- 是否使用真实账号：yes / no。
- 是否可能产生费用：yes / no / unsure。
- 是否出现额度、登录或认证错误：简述错误类别，移除完整错误正文中的敏感字段。
- 是否附上诊断包：yes / no；如果 no，可说明“因疑似敏感信息未附”。

## 停止线

出现以下情况请立即停止真实 Agent 测试：

- Agent 要求上传密钥、关闭安全软件、扩大系统权限或访问生产环境。
- 你看到未脱敏 token、cookie、私钥或客户信息进入日志 / 诊断包。
- Agent 在未确认情况下尝试破坏性 Git、递归删除或部署命令。
- 账号费用、额度消耗或服务端行为超出预期。
- 你无法判断该 Agent 是否会把私有上下文发送到外部服务。
