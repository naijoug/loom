# Loom Beta 安全说明

- **状态**: draft
- **适用阶段**: M0 发布对象与风险边界
- **关联文档**: `docs/release/beta-scope.md`

## 试用前确认

在运行 Loom Beta 前，请确认：

- 只在临时仓库、示例仓库或低风险个人仓库中试用。
- 不把 Loom 指向生产关键仓库、客户代码、商业秘密仓库或未备份项目。
- 不在需求、反馈、附件、文件名或命令参数中粘贴 token、password、API key、cookie、私钥或其它机密。
- 理解真实 Agent CLI 可能把上下文发送给对应服务商，且费用、额度、账号策略由试用者自己的配置决定。

## 本机能力边界

Loom 是本地桌面应用，核心能力包括：

- 读取用户选择的项目目录，用于生成计划、展示文件上下文和运行验证命令。
- 在用户选择的项目目录内执行配置好的命令或 Agent CLI。
- 保存任务历史、Agent 输出摘要、命令状态、退出码和调试证据。
- 在用户确认后导出总结或诊断包。

Loom 不是系统级沙箱。被调用的 Agent 或命令仍可能以当前系统用户身份读取可访问文件、创建文件、启动子进程或消耗网络服务额度。请只配置你信任的可执行命令。

## 不要用于这些场景

首轮 Beta 不适合：

- 生产数据库、线上部署、支付、权限、用户数据迁移等高风险任务。
- 含客户资料、商业合同、密钥、未公开财务或法律材料的仓库。
- 没有 Git、备份或可回滚手段的唯一工作副本。
- 需要企业合规审计、集中账号管理或团队权限隔离的环境。

## 真实 Agent 账号责任

如果你配置 Codex、Claude Code、OpenClaw、Hermes 或其它自定义 CLI：

- 账号登录、额度、计费、服务端日志、数据保留策略由对应工具和服务商决定。
- Loom 只能记录本地调用和结果摘要，不能替第三方服务保证隐私、成本或合规。
- 付费 Agent canary 不应作为默认 smoke；需要你明确选择并确认。
- 如果不确定 Agent 会发送哪些上下文，请先使用 dummy / fixture / echo 命令完成确定性试用。

## 诊断包与反馈

发送反馈前请人工复核：

- 截图是否包含私有路径、仓库名、客户名或聊天内容。
- 日志是否包含 token、cookie、Authorization header、环境变量或完整源码片段。
- 诊断包是否只包含本次低风险试用所需证据。

如果发现敏感信息已经进入诊断材料，请不要发送；先删除材料并在反馈中说明“诊断包因疑似敏感信息未附”。

## 安全停止线

出现以下情况请立即停止使用并反馈：

- Loom 请求或执行了你没有理解的破坏性命令。
- Agent 输出要求上传密钥、关闭安全软件、修改系统权限或访问生产环境。
- 诊断包中出现未脱敏机密。
- App 重启后任务历史、项目文件或配置异常损坏。
- 你无法判断某一步是否会把私有上下文发送给外部服务。
