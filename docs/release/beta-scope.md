# Loom 邀请制 Beta 范围说明

- **状态**: draft
- **适用阶段**: M0 发布对象与风险边界
- **关联计划**: `docs/plans/2026-08-07/10:00-beta-release-readiness.md`

## 一句话范围

本轮 Beta 是面向少量熟悉命令行和 Git 的开发者的邀请制试用，用来验证 Loom 的本地 AI 开发闭环是否能在非作者设备上完成一次安全、可回收、可反馈的 15 分钟 smoke。

## 目标试用者

优先邀请同时满足以下条件的人：

- 日常使用 macOS 开发，理解 Gatekeeper、终端命令和本机文件权限的基本含义。
- 至少熟悉一种 AI 编程 CLI，例如 Codex、Claude Code、OpenClaw、Hermes 或自定义命令行 Agent。
- 能在临时仓库、示例仓库或低风险个人仓库中试用，不需要把 Loom 接入生产关键项目。
- 愿意按照 `docs/release/beta-feedback-template.md` 回传复现步骤、截图、诊断包摘要或日志片段。

## 支持平台

首轮只承诺：

- macOS arm64。
- 本机安装并运行的桌面 App。
- 用户自备 Node / Rust / Agent CLI 等本地环境；Loom 只负责调用已配置的命令。

暂不承诺：

- Windows、Linux 或 Intel macOS 同步可用。
- 企业 MDM、受管设备、无管理员权限环境下的安装支持。
- 无命令行基础用户的完整引导。

## 推荐试用任务

首轮只建议做低风险任务：

1. 新建一个临时示例项目，或复制一个不含机密的个人项目。
2. 配置一个不会触碰生产服务的测试命令，例如 lint、unit test 或 echo fixture。
3. 让 Loom 完成一次“需求讨论 → 计划 → 实施/Review → 调试验收 → 总结导出”的最短闭环。
4. 导出诊断包前先人工复核内容，不发送包含 token、私密路径、客户代码或商业秘密的材料。

## 已知限制

- 公开签名、公证和下载页尚未完成；如果使用未签名构建，会出现 Gatekeeper 摩擦。
- 真实 Agent 调用可能消耗用户自己的额度，并可能把项目上下文发送给对应 CLI / 模型服务。
- Loom 不是操作系统级沙箱；经用户确认的命令仍以当前系统用户身份运行。
- 首轮反馈处理优先级以安装阻塞、安全风险、确定性 smoke 失败为先，功能扩张请求延后。

## 非目标

本轮不做：

- 插件市场、云同步、团队账号、远程协作。
- 生产环境部署、线上数据库迁移、真实客户项目自动修改。
- 默认启用真实付费 Agent canary。
- 对所有第三方 Agent CLI 的完整兼容性承诺。
- 将未签名、未公证、未附隐私说明的构建作为公开稳定版发布。

## 退出条件

出现任一情况应停止本轮 Beta 分发，并先修复或补充说明：

- 安装或首次启动在两名以上目标试用者设备上不可恢复地失败。
- 诊断包或日志导出包含未脱敏 token、密钥、客户路径或私有仓库内容。
- Loom 在未充分确认的情况下执行破坏性文件、Git 或生产外部命令。
- 任务历史、日志或配置损坏且没有可执行的清理/恢复步骤。
- 试用者普遍无法理解“真实 Agent 账号、额度和数据发送由用户自担”的边界。
