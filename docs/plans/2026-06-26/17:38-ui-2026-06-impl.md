## 1. 目标

- 把设计稿的「深色技术工作台」视觉语言（Linear/Claude 桌面端风格、等宽字体强调日志、Agent 配色编码）落地为 React 组件。
- 让 5 个核心流程页面在视觉与布局上与设计稿一致：规划讨论室 → 任务看板 → 执行中 → 调试验收 → 交付总结。
- 落地共享 Shell（侧栏 + 顶栏 + 4 段 miniStepper 步骤条），并复用已有的 `viewedStage` 机制做阶段联动。
- 迁移设计令牌到 `src/styles/theme.css`，统一深色基底。

## 2. 非目标

- 不重写后端 Rust 能力（Agent 适配器、Command Runner、PTY、持久化保持现状）。
- 不改任务状态机与编排逻辑（Loop Engineering 重构已在 10:21/14:54 计划落地）。
- 不新增插件市场、云同步、团队协作等 MVP 外能力。
- 不改 Tauri 前后端边界与 command 协议。
- 暂不强制实现深/浅双主题切换；本计划聚焦深色模式（设计稿默认形态）。浅色模式作为后续可选项。

## 3. 成功标准

- 桌面端预览（`scripts/preview.sh`，端口 1420）下，5 个页面视觉与对应设计稿一致：配色、间距、Agent 配色、miniStepper 状态色、等宽日志区。
- 顶栏 miniStepper 4 段（计划/实施/测试/完成）随任务真实阶段推进，且可点击回看历史阶段（沿用 `viewedStage`）。
- Agent 配色编码（Codex 绿 `#10A37F`、Claude 橙 `#D97757`、Hermes 紫 `#7C5CFC`）在所有出现 Agent 头像/徽章处一致。
- 设计令牌集中在 `src/styles/theme.css`，无散落硬编码颜色。
- `pnpm test`（单元测试）与 `pnpm smoke:visual`（视觉冒烟）通过。

## 5. 设计令牌与基础层（先行）

### 5.0 令牌命名策略（开工前必须先定，方案 A）

设计稿 `--loom-*` 与现有 `--bg/--text/--accent/--agent-*` **值相同、名不同**。采用**别名层**（方案 A，最省且可逆）：

- 在 `src/styles/theme.css` 内新增一层 `--loom-*` 别名，统一指向现有变量（如 `--loom-bg: var(--bg);`、`--loom-agent-codex: var(--agent-codex);`），覆盖背景层级 / 文字层级 / 语义状态色 / Agent 配色 / 圆角 / 字号 / 字体。
- 新增/重构的组件一律消费 `--loom-*`；存量 1144 处旧引用**不做全量改名**（避免不可控 churn），作为后续可选清理项。
- （备选 B：全量 find/replace 把旧引用改名为 `--loom-*`，量级约 1144 处，仅在确需单一命名空间时执行——本计划默认不走 B。）

### 5.1 基础类与字体

1. 把设计稿 `colors_and_type.css` 中的 Agent 头像基础类 `.loom-agent-avatar`（codex/claude/hermes/empty 四态）与状态圆点 `.loom-status-dot` **迁入**公共样式（这两类设计稿已写好，按 5.0 别名消费 `--loom-*`）。
2. 字体：**沿用现有自托管 `@fontsource/geist-mono`**，`--loom-mono` 经别名指向现有 `--mono`；**不新增 CDN 链接**。

## 8. 风险

- **令牌命名双轨期**：采用别名层（5.0 方案 A）后，仓内同时存在 `--loom-*`（新）与 `--bg/--text…`（旧）两套指向相同值的命名；缓解——新代码统一只消费 `--loom-*`，旧引用通过别名保持等价，避免破坏；如需收敛到单命名空间再执行备选 B（约 1144 处 find/replace）。新写代码的硬编码颜色用 `grep '#[0-9a-fA-F]\{3,6\}'` 复查。
- **viewedStage 与 miniStepper**：现枚举已是 4 段且与 `viewedStage` 联动成熟，本计划仅改状态色与标签，映射无需重做；缓解——M0 先回归阶段联动再铺开页面。
- **设计稿为静态 HTML，交互态（hover/激活/加载）需自行补全**：设计稿只画了稳态；缓解——沿用现有组件的交互态样式，仅迁视觉。
- **等宽字体**：Geist Mono 已由 `@fontsource/geist-mono` 本地自托管，离线安全，无 CDN 依赖；`--loom-mono` 经别名指向现有 `--mono`，仍保留 SF Mono / JetBrains Mono fallback 链。
- **响应式**：设计稿基于桌面固定视口，Tauri 窗口缩放时需保证不塌陷；缓解——Shell 用 flex + min-width:0 兜底。
