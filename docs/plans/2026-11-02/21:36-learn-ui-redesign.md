## 2. 目标方向（推荐，待确认）

1. **两栏布局**：去掉独立学习列表栏。左栏顶部是学习切换器（当前仓库名 + 下拉切换 / 新建），下面是页面目录；正文获得约 1000px。目录标题最多两行换行，不截断。
2. **精简头部**：标题 + commit / Agent 元信息；流水线状态收成一个进度指示（如 “2/13 页 · 生成中”），点开弹层看阶段详情与 Inventory 排除说明；全部完成且无警告时只显示页数。GitHub、日志、删除收进“更多”菜单，删除需确认；源码树开关保留。
3. **学习路径**：Overview 改为学习入口页，显示 L1–L3 分组卡片、每组已读 / 已生成数量和“从这里开始”；每页底部按学习顺序给出上一页 / 下一页；已读状态按设备保存（localStorage，失败可忽略）。
4. **按页生成**：未生成页打开后显示说明与“生成此页”按钮；目录用三种明确图标区分已生成 / 未生成 / 生成中；头部保留“生成剩余”。
5. **可读的架构图**：层名放在行上方而非左侧窄列；模块框按内容宽度换行显示全名；默认不画全部边，悬停或键盘聚焦模块时高亮它的依赖与被依赖并淡化其余；点击仍打开模块页。正文去掉与图重复的层/模块列表，保留模块说明。
6. 保持现有能力：中英文、深浅主题、700px 窄窗口（左栏可收起为抽屉）、键盘操作、源码引用查看器、日志、失败重试、存储错误提示。

### U1 完成记录（2026-11-02）
